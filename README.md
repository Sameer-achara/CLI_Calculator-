Smart CLI Calculator

A command-line based calculator developed using Python that performs basic arithmetic operations, scientific calculations, and unit conversions through an interactive menu-driven interface.

Features:-
Basic Arithmetic Operations
Addition (+)
Subtraction (-)
Multiplication (*)
Division (/)
Scientific Functions
Sine (sin)
Cosine (cos)
Tangent (tan)
Logarithm (log)
Square Root (sqrt)
Power calculation
Unit Conversion
Centimeter ↔ Inch
Kilogram ↔ Pound
Celsius ↔ Fahrenheit

Technologies Used:-
Python
Math Module
